So, what is Dummy Alogorithm & how this router works?

Let's take a look

Dummy Router
has 3 actions

1-Page Load 2-Link Click 3-PopState Event

1- Page Load

At page load the router take the routes and build the routesMap from it. This action has few steps explained next.

STEP 1

The router takes every route and convert it into something called the Dummy Route.

Route
path: "/users/[id]"
view: f
Dummy Route
path: "/users/[id]"
dummyPath: "/users/[x]"
parms: ['id']
static: ['users']
view: f
/users/[id]
dummyRoute: will be used as the keys for the routeMap itself.
params: is the array that contains all the dynamic params of the path ['id'].
static: is the array that contains all the static parts of the path ['users'] and will be used with the nav-links will explain that later.
STEP 2

The router will take the window (location.pathname) and convert it to a fixedPath and then to a dummyPath to match it with the the same dummyPath in the routeMap.

location.pathname users//[id]/
fixedPath /users/[id]
dummyPath /users/[x]
STEP 3

In this step the router will match the dummyPath with the same one in the routeMap which is a javaScript Map(hash table).

routeMap.get(/users/[id])

2- Link Click

On Link click the router do the same process as the (Page Load) but with small differences.

The router will compaire the pathname of the link's href with the dummyPath of the current pathname before matching it with the routeMap.

link === current
The same path

The router do nothing to avoid navigate to the same path

not the same

The router do the match and navigate if matches

3- PopState Event

When you go forward and back through the browser history this will trigger the popstate event.

In this action the browser will just match the path from the browser history and update the current dummyRoute in memory and render it's view.

Nav-link States

The nav-link has 3 states depends on the className of the nav-link so you can style them the way you want.

State 1

This state means that the current route is a child route of the nav-link route. For example: the link pathname = /users & the current pathname = /users/[id] so the className = "active"

State 2

This state means that the current route is exact the same as the nav-link route. For example: the link pathname = /users & the current pathname = /users so the className = "active exact"

State 3

This state means that the current route is completely different from the nav-link route. For example: the link pathname = /posts & the current pathname = /users so the className will be empty
